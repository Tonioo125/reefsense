ReefSense · architecture

From satellite heat and dive surveys to an explained reef map

An offline Python pipeline trains and validates the model and scores every reef; one container serves the API and the web app.

1Open data

Public datasets and APIs

  • NOAA Coral Reef Watch daily 5 km heat stress (DHW, SST anomaly), via ERDDAP
  • Global Coral-Bleaching Database 23,186 labelled dive surveys (BCO-DMO, CC BY 4.0)
  • MERMAID hard coral cover surveys
  • iNaturalist openly licensed coral photos within 10 km
  • UNEP-WCMC global coral reef extent
  • Curated support links donation pages checked by hand

2Pipeline

Python 3.11 · pandas · NumPy · GeoPandas · scikit-learn · LightGBM

  • Label surveys bleaching of 10% or more of colonies, from three survey methods
  • Heat stress for every reef regional NOAA grids: about 11 min instead of about 33 h
  • Train class-balanced LightGBM, 16 features: heat, depth, turbidity, exposure, cyclones…
  • Validate 5-fold CV grouped by ecoregion; later years, the 2016 event, unseen countries
  • Score every reef probability, per-feature contributions (TreeSHAP), NOAA gap
  • Context coral cover, photos, reef-area tiles, link check

3Model + data

data/processed

  • bleaching_model.joblib the trained LightGBM model
  • sites_scored.json 3,780 reefs: probability and reasons
  • Heat series 12 weeks of daily DHW per reef
  • Metrics + stress tests shown on the site as they are
  • Photos, coral cover cached, refreshed weekly
  • Reef-area tiles images only (licence: not downloadable)

4One container

Docker · FastAPI · Uvicorn · hosted on Fly.io

  • Reef API /api/reefs · /explanation · /heat-history · /survey-history
  • NOAA gap + history /api/noaa-gap · /api/bleaching-history
  • What-if scoring POST /api/predict re-runs the model live
  • Context /news · /photos · /support (news: Mongabay RSS, cached)
  • Web app the Vite build, served from the same origin

Deploy gate: the image build fails if the model, scored data or web app is missing or will not load.

5ReefSense

React 18 · TypeScript · Vite · Tailwind · shadcn/ui · Leaflet · Recharts

  • Resilience map 3,780 reefs, filters, NOAA-gap highlight, 1998–2020 replay
  • Reef report plain-language and expert views, heat record, what-if, model reasons
  • Restoration ranking your weights, live
  • Act report bleaching, support local groups, share a reef

Loaded by the browser directly: Esri basemap and imagery tiles, iNaturalist photo files.

Kept fresh by GitHub Actions

  • Daily NOAA heat stress for every reef (22:30 UTC)
  • Weekly bleaching-database version check, MERMAID coral cover
  • Weekly iNaturalist photos, donation-link check
  • Failed sources keep their last good data; each step has its own timeout

Kept honest by tests

  • pytest API and data-sync tests
  • Vitest ranking, explanations, imagery, support links
  • Wording test "predicted probability", never "proves" resilience
  • Validation in the open including where heat alone does as well (Japan)

DHW: Degree Heating Weeks, the heat stress accumulated over 12 weeks. TreeSHAP: LightGBM's exact per-feature contributions, which add up to each prediction.
